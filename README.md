## Get the source and build

```sh
git clone https://github.com/hollingsworthd/SLOP_CITY.git
cd SLOP_CITY
```

This repository is rooted at `~/knoxvillains` on the development machine.
The active game lives in [`slop-city-blender/`](slop-city-blender/), with the
Unity project in [`slop-city-blender/Unity/`](slop-city-blender/Unity/).
Use **Unity 6000.3.26f1**, with the Mac and/or WebGL export modules for those
builds. Obtain Unity under its own license; it is not supplied as AGPL source.
See the [game README](slop-city-blender/README.md) and
[Unity build instructions](slop-city-blender/Unity/README.md) for controls,
architecture, build commands and asset provenance.

The in-game **LICENSE + SOURCE** entry provides the full license offline and
an unauthenticated reader for public repository files. **Open on GitHub** opens
the repository directly. If the repository returns 404, its owner has not yet
enabled public access; the game never bypasses that restriction.

Generated builds, Unity caches, installed tools, local account configuration
and release archives are ignored. Original source, build scripts and project
settings belong in this repository; see [`.gitignore`](.gitignore).
